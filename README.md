# AirSense Pro

Smart Environmental Intelligence & Local IoT Monitor.

AirSense Pro is an ESP32-based environmental monitoring system
using the Bosch BME680 sensor.

## Features

- Temperature monitoring
- Humidity monitoring
- Atmospheric pressure monitoring
- Gas resistance measurement
- Relative air-quality scoring
- Historical telemetry
- Wi-Fi connectivity
- mDNS local dashboard
- Local web dashboard
- System telemetry
- Sensor health monitoring
- Local data storage

## Hardware

- ESP32
- Bosch BME680
- USB power supply
- Wi-Fi network
